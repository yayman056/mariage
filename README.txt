# Carte de visite — Démo

## Tester sur ton ordinateur
1. Décompresse le dossier.
2. Ouvre `index.html` dans Chrome, Firefox ou Edge.
3. La carte s'affiche directement. Aucun serveur ni installation n'est nécessaire.

## Personnaliser
Ouvre `script.js` et modifie les valeurs dans l'objet `business` :
- `name`, `initials`, `category`, `description`
- `phone` : numéro avec indicatif, pour le bouton Appeler
- `whatsapp` : indicatif pays + numéro, sans `+`, espaces ou tirets
- `instagram` : URL complète du profil
- `address` : adresse affichée
- `maps` : lien Google Maps à ouvrir

## Mettre en ligne
Dépose les trois fichiers (`index.html`, `style.css`, `script.js`) dans un dépôt GitHub, puis active GitHub Pages dans Settings > Pages. Tu obtiendras une URL publique à partager ou à convertir en QR code.

Note : les polices Google nécessitent Internet. Le reste de la carte fonctionne comme fichiers statiques.
